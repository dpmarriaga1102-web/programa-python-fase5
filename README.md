# Control de horas de empleados

## Descripción
Este programa está desarrollado en Python y permite calcular el total de horas trabajadas por diferentes empleados durante la semana.

## Funcionamiento
El programa almacena una lista de empleados, donde cada uno tiene un conjunto de horas trabajadas.

Luego realiza lo siguiente:
1. Suma las horas de cada empleado
2. Evalúa si supera las 40 horas semanales
3. Clasifica el resultado como:
   - "Sobretiempo" si trabaja más de 40 horas
   - "Horario Estándar" si trabaja 40 horas o menos
4. Muestra el nombre del empleado, el total de horas y su clasificación

## Ejecución
Para ejecutar el programa se usa el siguiente comando:

python programa.py
